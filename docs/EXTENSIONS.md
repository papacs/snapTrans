# 扩展功能

本轮按勾选项实现基础版本。表格提取和固定区域连续翻译放到后续，不增加到当前截图链路。

## 不变的主流程

- 翻译快捷键 / 框选松手后立即翻译，不先打开扩展面板。
- 扩展入口只出现在结果或截图编辑器中。纯文字提取保留原来的截图工具栏入口。
- 设置草稿与已保存开关隔离：取消不生效，保存后更新入口。效率功能默认开启，四个趣味功能逐项默认关闭。
- 前端所有 Wails 调用及浏览器演示均通过 `frontend/src/services/backend.ts`。

## 模块与数据

- `internal/config/features.go`：开关与旧配置默认值迁移。
- `app_extensions.go`、`internal/translator/actions.go`：独立文本操作与固定提示词。使用独立取消上下文、请求 ID 和 `text-action` 事件，不复用翻译的行编号协议。屏幕文字放入用户消息，明确视为数据而非指令。
- `pins_windows.go`：原生置顶位图窗，各自拥有消息线程；物理坐标、显示器工作区夹取、DPI 变化、托盘恢复。PNG 解码前检查格式和像素数。
- `internal/history/library.go`：最近翻译最多 50 条；收藏及学习卡片保留到用户取消收藏或删除。清空最近记录不会误删显式保存内容。
- `frontend/src/components/ExtensionWorkbench.vue`：共用工具面板，关闭时取消流并忽略晚到结果；联网操作先显示文字发送说明。
- `frontend/src/utils/extensions.ts`：换行、隐私框、同尺寸像素比较、卡片渲染和导出文本。图片不上传。
- `ExtensionSettings.vue` 与 `LearningLibrary.vue`：开关和本地卡片管理。
- `SettingsNavigation.vue` 与 `settings-navigation.ts`：固定六分类卡片、双行方向键导航；`App.vue` 保留各分类的设置草稿并将校验失败定位到对应字段。效率开关与趣味开关分开展示，学习卡片归入历史与收藏。

## 当前边界

- 贴钉保存的是当时的图片快照，不是持续刷新翻译。可分别创建原图和译图贴钉。
- 文字梗只依赖 OCR 文本，缺少视觉或文化背景时模型可能无法解释，不添加视觉模型。
- 学习卡片提供本地编辑保存、可选生成笔记和导出，不做后台复习通知。
- 隐私候选是邮箱和常见电话规则；OCR 漏字、拆行或不常见格式可能漏检。整块实心遮挡是保守的起点，不宣称自动脱敏完成。
- 对比只适用于相同尺寸、相同位置截图，不处理滚动、缩放、抗锯齿变化的自动对齐。
- 大图限制 1600 万像素，贴钉最多 12 个，模型输入上限 100 KB，导出 Markdown 上限 4 MB。

- 前端单元测试、类型检查、生产构建。

- `SNAPTRANS_TEST_NATIVE_PINS=1 go test -run TestNativePinSmoke -count=1 -v .`：可选 Windows 检查，会短暂创建真实贴钉；覆盖绘制、缩放、穿透恢复、关闭。日常测试默认跳过。
- `wails build -o snapTrans-extensions-20260831.exe`：独立构建，避免覆盖当前可执行文件。
- 混合 DPI 实际跨显示器拖动、真实 OCR 不同字体的识别率、用户配置模型的端到端表现，仍需在对应环境持续验证。
