## 素材与隐私

- 阅读背景是为文档自建的虚构 Fieldnotes 页面，原文与中文译文均为演示文案；不是第三方产品推荐或用户的真实阅读记录。
- 翻译图用于展示界面布局，不代表真实 OCR / 在线模型请求的准确度或性能测试。浏览器中使用受控事件接入，仍由应用现有 Vue 组件和画布排版渲染。
- 未读取用户 API 密钥、个人历史或桌面内容；没有外部模型调用。设置截图保留了浏览器预览标记。
- 未用 AI 重绘或修改产品界面。标注和分享卡片由程序自身生成，图片没有后期拼接。

## 更新方式

1. 在 `frontend/` 执行 `npm run build`，使用本地生产预览。
2. 用隔离浏览器和公开演示素材重现对应交互，不加载真实密钥或个人记录。
3. 翻译与截图编辑场景使用 1120×720 视口；设置页使用 680×780 视口；分享面板在足够高度的视口内截取完整弹窗。
4. 截图前等待字体、主题过渡和图片解码结束。检查选区、工具栏、开关与导出按钮是否完整可见。
5. 将核查后的 PNG 放入本目录，保持文件名稳定，并检查 README 相对链接和并排图片显示。

原始捕获脚本和调试产物留在忽略目录 `output/playwright/`；本目录只保存公开展示素材及说明。
