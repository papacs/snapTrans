# snapTrans 本轮改进与 AI 识图评估

日期：2026-08-31

## 已落地的改进

- 设置中的最近翻译显示本地日期、时分秒；点击展开完整内容；复制包含「原文 + 译文」，成功后显示勾选反馈。展示和复制时清理内部 [n] 编号，补译行按原顺序排列。
- 设置使用独立草稿：取消、关闭或进入截图会丢弃未保存内容；最小化保留草稿。语言和主题仍可预览。
- 开机自启延后到保存时应用；配置保存失败时恢复此前的自启状态，恢复失败会明确报错。保存期间禁止重复操作。
- 测试连接使用输入框里的 API 密钥、地址和模型，不保存它们。
- 翻译中断不再被伪装为完成：保留已有译文并显示未完成提示、重试入口。补译之后仍缺少行时返回错误。
- Esc 可取消识别、翻译或关闭结果；复制失败显示反馈，图片剪贴板不可用时不再把 base64 字符串冒充图片。
- OCR 常驻进程随实际路径、超时设置变化重新创建；OCR 的超时包含预热及降级过程，翻译超时独立计算。
- 重试及反向翻译复用最近一次成功 OCR 的文本和坐标。输入图片或 OCR 配置变化时重新识别，错误及已取消结果不缓存。
- 自定义指令、术语表存在时，不再被内置短语词典跳过。
- 复用截图原始帧，减少一次整屏 PNG 解码；截图缓存同时限制数量和字节（96 MiB，单张超大图片例外），隐藏窗口时清理。
- 流式覆盖的静态取色结果缓存；画笔移动合并到每帧重绘，不再逐事件复制整条笔迹。
- 长截图达到帧数或图像尺寸上限时显示提示并停止轮询，保留当前内容供用户完成。
- 设置窗口不再强制置顶；截图模式保持置顶。此前的可截屏修复和最小化按钮保持不变。
- 官方 DeepSeek 默认模型更新为 deepseek-v4-flash；只迁移官方地址上的旧默认 deepseek-chat，第三方网关模型别名不改。官方 V4 翻译请求关闭思考模式，避免不必要的推理等待。依据：[思考模式文档](https://api-docs.deepseek.com/guides/thinking_mode/)。
- Go CI 改为 Windows，与桌面代码的平台依赖一致。

## 是否去掉本地 OCR

**技术上可以，当前不建议直接删除。更合理的是保留本地 OCR 为默认，之后增加用户主动选择的 AI 识图模式。此次未启用云端识图、未上传截图、未删除 OCR 工具。**

snapTrans 的 OCR 不只是提取文字，还提供每段文本的坐标，让译文能覆盖原位置。直接让 AI 返回翻译容易；同时稳定输出原文、逐行坐标、对应译文，需要新的协议、布局方案和质量验证。若改用普通译文卡片，替换会简单很多，但原位翻译体验会改变。

DeepSeek 当前提供 deepseek-v4-flash-vision-exp，可读截图；普通文本模型不能直接接收图片。该视觉模型会在推理前缩放图片，大图缩至约 800×800 的总像素量，每张至多 384 个图像 token。长截图和高分屏小字因此需要专门测试，必要时切片。见[官方视觉文档](https://api-docs.deepseek.com/guides/vision/)。

| 维度 | 本地 OCR + 文本 AI | AI 直接识图 |
|---|---|---|
| 安装 | 需要 RapidOCR 及模型 | 无需捆绑 OCR，但需要视觉模型配置 |
| 隐私 | 截图留在本机；识别文字发给翻译服务 | 选区图像也发给服务商，包含其中的非文字内容 |
| 原位覆盖 | 使用 OCR 返回的文本框 | 需验证 AI 坐标或改为译文卡片 |
| 双语历史 | 原文已在本地得到 | 需要模型额外输出原文 |
| 离线提取文字 | 可以 | 不可以 |
| 延迟 | 本地识别后开始文本请求，可重用 OCR | 少一个本地步骤，但增加上传和视觉推理；未经实测不能断言更快 |
| 异常恢复 | 识别、翻译可分别重试 | 通常需重发图片，可能重复产生费用 |

## 成本示例：不会天然贵很多，但双语输出会增加费用

按当天官方 Flash / Flash Vision 高峰、无缓存价格：输入 $0.44 / 百万 token，输出 $1.32 / 百万 token；非高峰半价。见[官方价格表](https://api-docs.deepseek.com/quick_start/pricing/)。

下面是**计算示例，不是当前程序的账单或性能实测**：共同提示词 300 token、原文 500 token、译文 600 token、图片按 384 token；关闭思考、单张图片、不计切片/重试/坐标 JSON。

| 方案 | 每次输入 / 输出 token | 每 1,000 次约需 |
|---|---:|---:|
| 本地 OCR + 只生成译文 | 800 / 600 | $1.144 |
| AI 看图 + 只生成译文 | 684 / 600 | $1.093 |
| AI 看图 + 同时生成原文和译文 | 684 / 1,100 | $1.753 |

同样保留双语结果时，此示例约增加 53%，不属于数量级上涨。只生成译文的方案缺少双语历史需要的原文，不能当作完全等价替代。实际费用取决于服务商、文字密度、输出协议、图片切片和失败重试；其他视觉模型不适用这组价格。

建议下一步先做可选视觉模式的小样本对比，覆盖浅色/深色界面、细小字体、表格、混合中英文、长截图；记录识别错误、缺行、坐标偏移、首字和总耗时、账单 token。通过这些指标后，再决定是否提供不捆绑 OCR 的轻量发行包。
