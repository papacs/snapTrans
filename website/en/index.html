Essential workflow

Speed is more than one less button

Translation should not interrupt reading.

snapTrans folds capture, OCR, translation, and presentation into one action. There is no confirmation dialog and no second input box to find.

  1. 01

    Press the shortcut

    Alt + Q by default. A reliable text selection is read directly; otherwise screen selection opens.

    Alt + Q
  2. 02

    Release the mouse

    Local RapidOCR starts immediately and determines the translation direction.

    0 confirmations
  3. 03

    Keep reading

    The translation streams into the original region. Copy, reverse direction, or simply continue.

    In place

05

Questions

A few things
worth knowing.

Do I need an API key?

Not for capture or local OCR. Online translation needs a key for DeepSeek, LiteLLM, or another OpenAI-compatible provider, which may charge separately.

Does the model receive my screenshot?

No. RapidOCR recognizes the screenshot locally and snapTrans sends only the resulting text for translation.

Is macOS supported?

The current target is Windows 10/11. A Mac version is planned, with native work required for capture permissions, shortcuts, and secure key storage.

When will it reach Microsoft Store?

Store certification is being prepared. For now, download v0.2.0 from GitHub Releases.
