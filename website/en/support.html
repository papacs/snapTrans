Solve the problem first

Support

Start with the common fixes below. If the problem remains, include your Windows version, snapTrans version and what you observed in your email.

Get started

  1. Run snapTrans; it will stay in the system tray.
  2. Open Settings and enter the API key, endpoint and model name.
  3. Check RapidOCR status and save.
  4. Select text or press Alt + Q to translate a screen region.

Translation does not respond

Run Connection Test in Settings. Check the API endpoint, exact model ID and account balance. OpenAI-compatible endpoints often end in /v1; the DeepSeek default is already configured.

OCR is unavailable

Keep the RapidOCR-json folder beside snapTrans.exe, or select the full path to RapidOCR-json.exe in Settings.

The selection is offset

Tell us the number of displays, scaling ratio of each display and primary-display position. DPI and cross-display issues need these details for reproduction.

Shortcut conflict

The defaults are Alt + Q for translation and Alt + W for screenshot markup. Choose combinations not already used by another app.
