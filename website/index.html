常见问题

开始前，你可能想知道。

一定要配置 API Key 吗？

截图和本地 OCR 不需要。在线翻译需要配置 DeepSeek、LiteLLM 或其他 OpenAI-compatible 服务的 API Key。服务商可能单独收费。

截图会被发送给模型吗？

不会。RapidOCR 在电脑本地识别截图，翻译时只发送识别出来的文字。你主动使用解释、摘要等功能时也只发送文字。

支持 macOS 吗？

当前正式目标是 Windows 10/11。macOS 版本在规划中，系统截图、权限、快捷键和密钥存储需要分别适配。
