说清楚数据去向

隐私政策

生效日期：2026 年 9 月 4 日。我们用尽量直白的语言说明 snapTrans 在什么时候处理哪些数据。

概要

snapTrans 不要求注册账户，不包含广告或遥测。截图像素和 OCR 过程保留在你的设备上；只有当你主动请求翻译或其他 AI 文字处理时，相关文字才会发送给你配置的第三方模型服务。

应用处理的数据

截图与 OCR

屏幕截图由 Windows 本地捕获，文字识别由本机的 RapidOCR 完成。snapTrans 不会把截图像素、标注图片或桌面内容上传到我们的服务器。

翻译与 AI 文字功能

当你主动使用翻译、解释、摘要、梗解释或生成学习笔记时，snapTrans 会把对应文字发送到你在设置中配置的 OpenAI-compatible API 地址。该服务商会按照它自己的隐私政策处理请求。请不要对不受信任的服务配置 API 地址。

API Key 与设置

API Key 和应用设置保存在当前 Windows 用户的本地配置目录。Windows 版本使用 DPAPI 加密 API Key。我们无法读取或恢复你的密钥。

本地历史与日志

翻译历史、收藏、学习卡片和诊断日志仅保存在当前设备。它们可能包含原文和译文。你可以在应用中清理相关数据，卸载应用时也可以删除其本地数据目录。

网站数据

本网站不设置产品分析或广告 Cookie。网站托管服务商 Cloudflare 可能为传输、安全和滥用防护处理 IP 地址、请求时间、浏览器信息及安全日志，具体取决于其服务政策。

我们不会做的事

  • 不会出售个人信息。
  • 不会使用截图训练模型。
  • 不会在后台上传截图或剪贴板内容。
  • 不会把 API Key 发送给 snapTrans 自有服务器。

你的选择

你可以更换或删除 API 配置、关闭历史功能、清理本地记录，或者停止使用相关模型服务。需要删除通过支持邮件主动发送给我们的内容时，请联系我们。

儿童隐私

snapTrans 是通用效率工具，不以儿童为目标，也不会有意收集儿童个人信息。

政策更新

如果数据处理方式发生实质变化，我们会在本页更新生效日期，并在适当情况下通过应用或发布说明告知用户。
