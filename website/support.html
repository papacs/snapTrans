使用帮助

先从下面的常见问题开始。如果仍然没有解决，邮件里附上 Windows 版本、snapTrans 版本和问题现象。

开始使用

  1. 运行 snapTrans，它会进入系统托盘。
  2. 打开 Settings，填写 API Key、API 地址和模型名称。
  3. 检查 RapidOCR 状态并保存。
  4. 选中文字或按 Alt + Q 框选翻译。

翻译没有响应

先在设置中点击连接测试，确认 API 地址、模型 ID 和余额。OpenAI-compatible 地址通常以 /v1 结尾，但 DeepSeek 官方地址可以使用应用默认值。

OCR 不可用

确认 RapidOCR-json 文件夹与 snapTrans.exe 一同安装，或者在设置里选择 RapidOCR-json.exe 的完整路径。

选区位置偏移

请告诉我们显示器数量、每块屏幕的缩放比例以及主显示器位置。DPI 与跨屏坐标问题需要这些信息才能复现。

快捷键冲突

默认翻译快捷键是 Alt + Q，截图标注是 Alt + W。可以在设置中改成未被其他应用占用的组合。
